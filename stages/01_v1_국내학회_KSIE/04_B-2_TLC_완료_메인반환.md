## 1. 확정 사항

### 1-1. 산출 방식 — 옵션 A 채택 (B-Spline 1차 도함수 평균)

| 항목 | 결정 |
|---|---|
| 산출 공식 | `estimateEffect`의 B-Spline 추정치를 분석 기간 내 6개 정수 연도(2020~2025)에서 1차 도함수로 미분한 뒤 평균 |
| 평가 시점 | **2020, 2021, 2022, 2023, 2024, 2025** (Inner6) |
| Boundary 제외 사유 | B-Spline 도함수가 boundary knot(2019, 2026)에서 수치적으로 폭주 — 2026 시점 기준 다른 시점 대비 6배 이상의 절대값을 보이며 평균 오염 확인 |
| 점추정값 | STM Global uncertainty 시뮬레이션 25회 평균 |
| 신뢰구간 | 시뮬레이션 25회의 2.5%, 97.5% 분위수 (95% CI) |
| 스케일 | 기존 OLS와 동일하게 × 100 (가독성) |

### 1-2. 2025년 데이터 처리 — 포함

- **이유**: 옵션 A의 B-Spline 도함수 평균은 OLS와 달리 sparse 끝점에 강하게 끌리지 않음
- **단**: 출원/공개 기준 비대칭 문제는 별도로 본문에 명시 필요 (아래 수정 #6 참조)

### 1-3. 시간 기준 명시 — STM은 공개일(Publication Year) 기준

- 데이터 수집/Phase 구분: **출원일(Application Date)** 기준
- STM 시간 공변량: **공개일(Publication Year)** 기준
- 이는 텍스트 기반 모형의 특성상 가용 시점(공개일)에 의존할 수밖에 없는 필연적 분리이며, 학회 디펜스의 핵심 정당화 논거

## 4. 본문 4.2.3 수정 일람표 — 6개 핵심 포인트

### 수정 #1: 방법론 절 (3.7.5절 ⑤항) — 산출 방식 명시
**위치**: 3.7.5절 ⑤ "성장 모멘텀은 각 토픽의 θ 값..." 단락 전체

**교체 본문**:
> "성장 모멘텀은 STM 본체의 시간 공변량 추정 방식과 일관되도록, estimateEffect의 B-Spline 추정치를 활용하여 산출하였다. 구체적으로, 분석 기간 내 6개 정수 연도(2020~2025)에서 B-Spline 함수의 1차 도함수를 산출한 뒤 평균하고 100을 곱한 값으로, 연도가 1년 증가할 때 해당 토픽의 비중이 평균적으로 얼마나 변화했는가를 나타내는 시계열적 추세 방향성 지표이다. 양수이면 해당 기간 동안 비중이 증가한 것(성장)이고, 음수이면 감소한 것(쇠퇴)이다. 분석 기간의 boundary knot(2019, 2026)을 평균에서 제외한 것은 B-Spline 도함수가 boundary 영역에서 수치적으로 불안정해지는 특성을 반영한 처리이다. 또한 STM의 Global uncertainty 시뮬레이션(25회) 결과를 활용하여 모멘텀의 95% 신뢰구간을 함께 산출하였다. 이는 단순 OLS 추세선 대비 비선형적 성장 패턴을 정밀하게 포착하면서도 통계적 유의성을 검증할 수 있다는 장점이 있다."

**추가 본문**:
