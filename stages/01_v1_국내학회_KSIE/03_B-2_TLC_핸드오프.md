# B-2 핸드오프: TLC 성장 모멘텀 산출 방식 변경

## 1. 이전 진행 상황 요약 (Ingest 프로토콜)

본 작업은 IP5 핀테크 특허 STM 분석 논문 **「IP5 핀테크 특허의 동태적 분석」** 의 5월 13일 국내학회 제출 직전 Phase 1 코드 수정 작업이다. 작업의 절대 원칙:

- **특허 데이터(21,381건, K=20 STM 결과)는 절대 변경하지 않는다.**
- 분석 코드의 산출 방식만 수정한다.
- 본문 수치는 첨부 파일에 명시된 수치만 인용한다 (Zero Hallucination).
- B-2와 병렬로 다른 채팅에서 B-1(시멘틱 필터링 검증)과 B-3(Gompertz TMR 부록 보강)가 진행 중이다.

이미 확정된 사항:
- 3.4절 시드/안티시드 개수(157/443)는 5.11일 기준 최종본에서 이미 정정되어 있고, embedding.py 코드와의 일치 검증도 완료되었다.

## 2. 작업 목적

### 2-1. 배경 — 교수님 피드백 4번
TLC(Technology Life Cycle) 성장 모멘텀이 현재 **단순 OLS(`lm()`)** 로 산출되고 있는데, 다음 두 가지 문제가 있다.

- **STM 본체와의 비일관성**: STM 본체에서는 시간 공변량을 **B-Spline 비선형 함수**로 추정한다. TLC 모멘텀만 단순 직선 회귀로 산출하는 것은 방법론적 일관성을 해친다.
- **2025년 데이터의 하향 편향**: 2025년 공개 특허는 publication lag(약 18개월 심사 대기)으로 데이터가 sparse하다. 이를 OLS에 그대로 포함하면 모멘텀이 인위적으로 하향 편향될 수 있다.

### 2-2. 학술적 맥락
TLC 분석의 핵심은 각 토픽의 "성장 모멘텀"을 측정해서 유망 기술 / 포화 기술 / 하향 기술을 구분하는 데 있다. 모멘텀 산출 방식이 STM 본체의 추정 방식과 일치하지 않으면, 동일 데이터에서 도출된 두 결과가 서로 다른 기술 진화 양상을 시사할 수 있다.

## 4. 의사결정 필요 사항 (작업 시작 전 반드시 확정)

### 4-1. 산출 방식 (옵션 A vs B)

| 옵션 | 방식 | 장점 | 단점 |
|---|---|---|---|
| **A (권장)** | `estimateEffect`의 B-Spline 추정치를 분석 기간 중간점에서 1차 도함수로 미분 | STM 본체와 동일한 비선형 함수 사용, 방법론적 일관성 확보 | 구현 복잡도 증가 |
| **B** | 기존 OLS 유지 + 한계 각주 명시 | 코드 변경 최소화 | 비일관성 문제 미해결, 본문 약점 잔존 |

→ 교수님과의 합의 방향이 없을 경우 **옵션 A** 권장.

### 4-2. 2025년 데이터 처리
- **포함 시**: publication lag 한계를 본문 4.2 도입부 또는 각주에 1줄 명시
- **제외 시**: 데이터 윈도우 변경 사유를 본문에 명시

## 7. 본문 인용 문구 초안

### 7-1. 산출 방식 변경 명시 (4.2.3 또는 방법론 절)
> "기술 수명주기(TLC) 분석을 위한 성장 모멘텀은 STM 본체의 시간 공변량 추정 방식과 일관되도록, `estimateEffect`의 B-Spline 추정치를 분석 기간 중간점에서 1차 도함수로 미분하여 산출하였다. 이는 단순 OLS 추세선 대비 비선형적 성장 패턴을 정밀하게 포착할 수 있다는 장점이 있다."

### 7-2. 2025년 데이터 포함 시 각주
> "2025년 공개 특허는 통상 18개월의 심사 대기로 인해 일부 데이터가 누락되어 있을 수 있으나, 본 연구는 분석 기간의 연속성을 위해 포함하였다. 해석 시 publication lag으로 인한 하향 편향 가능성을 유의할 필요가 있다."
