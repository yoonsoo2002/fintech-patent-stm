## B-3에서 알아야 할 것 — 짧게

### 1. TLC 사분면 분류 확정 (Inner6 B-Spline 기준)

본문 4.2.3의 **TLC-TMR 교차 검증** 단락에서 평균 TMR을 재산출할 때 아래 토픽 구성을 사용할 것.

#### 성장 토픽군 (Q1 + Q2) — 10개
T17, T9, T11, T8, T7, T13, T3, T15, T4, T19

#### 하락/포화 토픽군 (Q3 + Q4) — 10개

→ **기존 본문 인용값 "Q1·Q2 평균 TMR 75.9% / Q3·Q4 평균 TMR 81.7%"는 OLS 기반 사분면 구성**으로 산출된 것. 본문에 그대로 두면 새 사분면과 어긋남. B-3에서 TMR 값으로 재계산 후 갱신 필요.

## 3. CSV 컬럼 인계 — TMR 채우기

**파일**: `STM_TLC_TMR_Combined_Table.csv` (작업 디렉토리에 존재)

**컬럼 구성**:
```
Topic, Topic_Label(한글), Mega_Cluster, Cluster_Name(한글),
Proportion_pct, Growth_Momentum(BSpline), Impact, TMR_pct(NA), Quadrant
```

→ B-3에서 산출한 TMR 값을 **`TMR_pct` 컬럼에 채워넣으면** 본문 표 4.2.4 완성.

**병합 시 주의**: CSV는 사분면 순(Q1→Q4)으로 정렬되어 있음. B-3 산출 결과(아마도 T1~T20 순)와 병합 시 `Topic` 컬럼을 키로 사용해 join 권장.

```r
# 예시 코드
df_tlc_table <- read.csv("STM_TLC_TMR_Combined_Table.csv", fileEncoding = "UTF-8")
df_tmr_new <- # B-3에서 산출한 TMR 결과 (Topic, TMR_pct, ...)
df_final <- merge(df_tlc_table %>% select(-TMR_pct), 
                  df_tmr_new %>% select(Topic, TMR_pct), 
                  by = "Topic", all.x = TRUE)
```

## 4. B-3 작업 시 추가 준수 사항

### 4-1. 시각화 해상도
- **모든 그림은 dpi 450 이상** (윤수 합의 사항)
- 기존 `Fintech_Project.R`의 `dpi = 300` 부분을 새 코드에서는 `dpi = 450`으로

### 4-2. 시간 기준 통일
- TMR도 STM과 동일하게 **공개일(Publication Year) 기준**으로 산출 (이미 그렇게 되어 있을 것으로 추정)
- 본문에 이미 "공개 시점 기준" 설명이 들어가므로 별도 추가 명시 불필요

### 4-3. 데이터 윈도우
- B-2는 평가 시점을 2020~2025 (boundary 제외)로 했으나, **Gompertz 누적 곡선 피팅**은 다른 문제임
- TMR 산출에는 2019~2026 전체 또는 2019~2025 사용 가능 (B-3에서 판단)
- 단, 2026년 데이터가 178건으로 매우 sparse한 점 유의

## 6. B-3 산출 후 메인 채팅 반환할 항목

1. 토픽별 TMR_pct 값 (T1~T20)

5. 채워진 `STM_TLC_TMR_Combined_Table.csv` (최종 본문 표 4.2.4용)
6. TMR 부록 표 (`STM_TMR_Detail_Appendix.csv` 등)
