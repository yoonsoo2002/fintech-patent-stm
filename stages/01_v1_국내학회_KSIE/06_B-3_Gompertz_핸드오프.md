# B-3 핸드오프: Gompertz TMR 부록 보강

## 1. 이전 진행 상황 요약 (Ingest 프로토콜)

본 작업은 IP5 핀테크 특허 STM 분석 논문 **「IP5 핀테크 특허의 동태적 분석」** 의 5월 13일 국내학회 제출 직전 Phase 1 코드 수정 작업이다. 작업의 절대 원칙:

- **특허 데이터(21,381건, K=20 STM 결과)는 절대 변경하지 않는다.**
- 분석 코드의 산출 방식만 수정한다.
- 본문 수치는 첨부 파일에 명시된 수치만 인용한다 (Zero Hallucination).
- B-3와 병렬로 다른 채팅에서 B-1(시멘틱 필터링 검증)과 B-2(TLC 성장 모멘텀)가 진행 중이다.

이미 확정된 사항:

- **B-3는 본문 4.2.3 본 수치(TMR%)를 변경하지 않는다. 부록만 보강하는 작업이다.**

## 2. 작업 목적

### 2-1. 배경 — 교수님 피드백 5번
Gompertz S-곡선 적합으로 산출되는 기술 성숙도(TMR, Technology Maturity Ratio)가 현재 다음 두 가지 한계를 안고 있다.

- **수렴 진단 미보고**: `nls()` 적합 결과의 수렴 여부, 반복 횟수, 허용 오차 등이 보고되지 않음.
- **신뢰구간 부재**: 파라미터 (α, β, γ) 추정치만 보고되고, 95% 신뢰구간이 없어 추정 정확성을 판단할 수 없음.

추가로, Gompertz 적합은 7개 시점(2019~2025) 데이터를 사용하는데, **3개의 파라미터를 추정하기에는 자유도가 낮다**. 이는 본문에 명시적으로 한계로 표기해야 한다.

### 2-2. 학술적 맥락
비선형 회귀 적합 결과는 다음 정보를 함께 보고하는 것이 학술적 관례:
- 추정 파라미터 (점추정)
- 95% 신뢰구간 또는 표준 오차
- 수렴 진단 (수렴 여부, 반복 횟수)

이를 누락하면 "추정값 자체가 안정적인가"라는 비판에 답변할 수 없다.

## 6. 본문 인용 문구 초안

### 6-1. 본문 4.2.3에 추가할 한계 명시 1줄
> "Gompertz S-곡선의 파라미터 추정은 7개 시점(2019~2025) 데이터에 기반한 탐색적 추정이며, 자유도의 제약상 추정치의 정밀도에는 한계가 있음을 부록 <표 B-1>의 신뢰구간을 통해 함께 보고한다."

### 6-2. 부록 도입 1문단
> "본 부록은 4.2.3절에서 보고한 토픽별 기술 성숙도(TMR) 산출에 사용된 Gompertz 적합 결과의 진단 정보를 제시한다. 각 토픽에 대해 `nls()` 비선형 회귀의 파라미터 추정치 (α, β, γ), 95% 신뢰구간, 수렴 여부 및 반복 횟수를 정리하였다. 본 모형은 7개 시점 데이터에 3개의 파라미터를 적합한 것으로, 자유도의 제약상 신뢰구간이 다소 넓게 나타날 수 있으며 이는 본 연구의 한계로 명시한다."

### 6-3. 5장 한계 절에 추가할 1줄
> "Gompertz 모형은 7개 시점에 3개 파라미터를 적합한 모형으로 자유도의 제약이 있으며, 향후 시계열이 확장됨에 따라 추정의 정밀도가 개선될 것으로 기대된다."

## 7. 진행 순서

1. `Fintech_Project.R` 열고 `nls()` 호출부 식별 (라인 1544 부근)
2. 기존 적합 결과 객체 구조 확인
   - `str(nls_result)` 출력으로 어떤 정보가 들어있는지 파악
3. 진단 정보 추출 코드 추가:
   ```r
   conv  <- nls_result$convInfo$isConv
   iter  <- nls_result$convInfo$finIter
   tol   <- nls_result$convInfo$finTol
   ```
4. 신뢰구간 산출:
   ```r
   ci <- tryCatch(
     confint(nls_result, level = 0.95),
     error = function(e) NULL
   )
   ```
   - 실패 시 (`ci == NULL`): `boot` 패키지로 케이스 부트스트랩, B=1000, `set.seed(2026)`
5. 20개 토픽 전체에 대해 반복 (이미 존재하는 loop에 진단 추출 코드 삽입)
6. 결과를 `STM_Gompertz_Diagnostics.csv`로 저장
7. 본문 4.2.3에 한계 명시 1줄 추가
8. 부록 도입 1문단 + 표 삽입

## 10. 주의사항

- STM 모델 객체는 **재학습하지 않는다**. `STM_full_workspace_Phase0.RData`를 `load()`로 불러와 사용할 것.
- 본문 본 수치(TMR%)는 절대 건드리지 않는다. 부록만 추가.
- `nls()` 적합이 수렴 실패한 토픽이 있을 경우:
  - 그 토픽은 부록 표에 `convergence = FALSE`로 표기
  - 점추정치도 표기하되 "신중하게 해석"이라는 각주 추가
  - 본문에 영향을 미친다면 메인 채팅으로 반환
- 부트스트랩 사용 시 `set.seed(2026)`로 재현성 확보 필수 (`Fintech_Project.R` 다른 부분에서도 2026 시드 사용 중).
- 이 md 파일이 첨부된 새 채팅에서, 추가로 `Fintech_Project.R`, `STM_Topic_TMR_Results.csv`, `Topic_Yearly_Mean_Values_Filtered.csv`, `논문_인수인계_20260511.md`가 동일 프로젝트 내에 보이는지 확인 후 시작할 것.
