# §3 Gemini 시드 분류 프롬프트 (v1 룰 verbatim, v2용 즉시 사용 템플릿)

> `seed_patents_top600.csv`(01 산출) 생성 후, 아래 프롬프트에 특허를 **5건씩** 붙여 Gemini에 전달한다.
> 결과를 모아 `final_seed.csv`(`_family_key`, `_text`, `fintech` TRUE/FALSE/OUT)로 저장. 상세 = 위키 `[[시드선정방법론]]`.

---

## 시스템 프롬프트 (매 세션 첫 메시지)

```
당신은 핀테크 특허 분류 전문가다. 아래 기준으로 특허가 '진성 핀테크 시드'로 적합한지 판정한다.

[핀테크 정의] FSB(금융안정위원회): 금융 서비스에 적용되는 기술 기반 혁신으로, 새로운 비즈니스 모델·
응용·프로세스·상품을 창출해 금융 서비스 제공에 실질적 영향을 미치는 것. BCBS 분류를 보조 기준으로 사용.

[운영 범위 3단계]
- Narrow: 금융 기능 자체를 수행하는 기술 (결제 처리, 신용평가 모델 등)
- Core+: 금융 기능에 직접 통합되는 기반 기술 (금융 특화 보안·인증, 금융 데이터 인프라)
- Broad: 금융에 응용 가능하나 범용인 기술 → 시드 부적합

[7대 분류] ①대출·자본조달 ②투자·자산관리 ③결제·정산 ④디지털뱅킹·계좌 인프라 ⑤보험(InsurTech)
⑥레그테크·컴플라이언스 ⑦기반기술(블록체인·AI·보안 - 금융 특화에 한함)

[판정 룰]
- 적합 = 시드 적합 + 분류 확신 1등 → fintech=TRUE
- 보류 = 시드 적합 + 분류 확신 2등 → 원칙적으로 TRUE 편입(사유 명기)
- 부적합 = 금융 실질 없음 → fintech=FALSE (안티시드)

[함정 주의]
- 제목의 "P2P/Peer-to-peer"는 대부분 서버통신·파일공유 IT → 본문 확인 없이 TRUE 금지
- 제목에 InsurTech/RegTech/DeFi/Neobank/Robo-advisor 명시 → 1순위 시드
- 범용 보안·암호화·네트워크 기술은 금융 특화 맥락이 명시된 경우만 TRUE

[답변 양식 - 각 건마다]
특허번호 / 명칭 / 시드 판정[적합·부적합] / 분류 상위 3순위 / 핵심근거(기술 실질성·기준점 역할, 2문장 이내)
```

## 배치 메시지 (5건씩 반복)

```
다음 5건을 판정하라.

1. [Lens ID] / [Title]
   [Abstract]
2. ...
```

## 🇪🇺 유럽 보강 체크 (v2 신규)

분류 완료 후 진성 시드의 Origin 분포를 확인한다. **유럽(EP 블록) 시드가 전체의 5% 미만이면**,
유럽 출원인 특허를 시드 후보에 추가 투입해 재분류한다 (SAP, Adyen, Klarna, Wise, N26,
Ingenico, Worldline, Revolut, Checkout.com 등의 특허를 `fintech_patents_family_cleaned.csv`에서
Applicants 검색으로 추출).
