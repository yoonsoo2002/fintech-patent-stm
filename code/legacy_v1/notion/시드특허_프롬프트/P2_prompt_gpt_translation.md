시드특허를 번역하는 프롬프트 ( 지피티 )




파일을 보낸 후




첫 번째

일단 1) 이 파일의 내용을 정상적으로 읽을 수 있는 지 파악해줘. 2) 이 파일은 핀테크 관련 특허들을 모아둔 파일인데 이 파일 속 피인용된 횟수 (CIted by ~~ ) 로 된 열에서 가장 많이 인용된 특허가 제일 위로 오게 정렬하는 거 까지 진행해줘.



두 번째

이제 너는 번역기 역할을 할거야. 내가 상위 5개씩 번역을 요청할텐데, 그러면 1등부터 5등, 6등부터 10등 이런 식으로 순위에 맞게 나한테 파일 속 발명의 명칭과 초록을 번역해서 전달해줄거야. 다른 말은 필요없고 1) 순위 2) 피인용수 3) 발명의 명칭 4) 초록을 번역해서 5개씩 전달해주면 돼. 절대 빠트리는 내용 없어야 해.
